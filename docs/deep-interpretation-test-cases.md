# Deep Interpretation Test Cases (3-card spread)

Mục tiêu: kiểm thử chất lượng kiến giải sâu bằng expected characteristics thay vì fixed text.

## Bộ case trọng tâm
1. Healing Arc — `Three of Swords (U) -> Temperance (U) -> Star (U)`
2. Hard Reset — `Tower (U) -> Death (U) -> Devil (R)`
3. Career Rebuild — `Eight of Pentacles (U) -> Two of Wands (U) -> Emperor (U)`
4. Illusion to Clarity — `Moon (U) -> Hanged Man (U) -> Sun (U)`
5. Control Conflict — `Chariot (R) -> Justice (U) -> Strength (U)`
6. Emotional Reset — `Five of Cups (U) -> Ace of Cups (U) -> Lovers (R)`
7. Burnout Signal — `Ten of Wands (U) -> Devil (U) -> Four of Swords (U)`
8. Financial Shock to Recovery — `Five of Pentacles (U) -> Wheel of Fortune (U) -> Nine of Pentacles (U)`
9. Ego Correction — `Magician (R) -> Judgement (U) -> World (U)`
10. Trust Repair — `Devil (U) -> Tower (R) -> Star (U)`
11. Direction Through Discipline — `Fool (U) -> Hermit (U) -> Chariot (U)`
12. Relationship Threshold — `Two of Cups (U) -> Justice (R) -> Death (U)`
13. Anxiety Cycle — `Nine of Swords (U) -> Temperance (R) -> Strength (R)`
14. Strategic Pivot — `Emperor (R) -> Wheel of Fortune (R) -> Hanged Man (U)`

## Hướng dẫn chấm nhanh
- Có đủ 3 trục thời gian và chuyển pha hợp lý.
- Narrative nhất quán, không mâu thuẫn.
- Có cá nhân hóa theo bối cảnh case.
- Có tối thiểu 3 hành động cụ thể.
- Không dùng template sáo rỗng lặp lại.
- Không vi phạm red flags theo rubric.
