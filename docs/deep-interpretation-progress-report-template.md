# Deep Interpretation Progress Report Template

Mục tiêu: mẫu báo cáo tiến độ/chất lượng theo stage để leader cập nhật user minh bạch và dễ hiểu.

## Header
- Dự án: Nâng cấp chất lượng kiến giải sâu (Tarot 3 lá)
- Stage: [Stage 1/2/3]
- Trạng thái tổng: [On track / At risk / Blocked]

## Tóm tắt cho user
- Đã hoàn thành gì trong stage này.
- Chất lượng cải thiện ra sao.
- Bước tiếp theo là gì.
