# Tarot Vietnamese Interpretation Style Spec (Phase 1)

Mục tiêu: chuẩn hóa ngôn ngữ kiến giải Tarot thuần Việt, dễ hiểu, nhất quán cho engine triple spread.

## Quy tắc chính
- Dùng tiếng Việt tự nhiên, gần gũi, câu ngắn.
- Tránh pha tiếng Anh trong phần diễn giải, trừ tên lá bài khi cần nhận diện.
- Dùng xưng hô nhất quán: bạn.

## Mapping thuật ngữ
- insight -> điểm sáng cốt lõi
- warning -> điều cần tránh
- actions -> việc nên làm
