# Deep Interpretation Quality Rubric

Mục tiêu: đánh giá chất lượng output kiến giải sâu cho trải bài 3 lá (Quá khứ / Hiện tại / Tương lai), tránh trả lời kiểu template chung chung.

## Trọng số gợi ý
1. Độ sâu phân tích theo 3 trục thời gian — 25%
2. Độ nhất quán nội dung giữa 3 lá — 20%
3. Mức độ cá nhân hóa theo ngữ cảnh user — 20%
4. Tính hành động được — 20%
5. Tránh sáo rỗng / lặp template — 15%
